# Luna Live2D — Prompt 10: Technical Layer Map

## Scopo
Definire la struttura finale dei layer PSD/Cubism dopo approvazione delle tavole artistiche.

## Regole obbligatorie
Applica `00_PROPORTION_LOCK.md`.
Usa METRIC MASTER e stesso outfit canonico statico/deformabile approvato.

Questa è una tavola tecnica, non una nuova reinterpretazione artistica.

## Figura base
Mostra solo una BASE CLEAN frontale neutra di Luna con lo stesso outfit canonico statico. Nessun accessorio dinamico montato sulla figura.

## Gruppi layer
### BODY
head/base face, neck, torso, chest deform region, shoulders L/R, arms L/R, hands L/R, pelvis, legs L/R, feet L/R.

### FACE
eyebrows L/R, eye whites L/R, irises L/R, pupils L/R, upper/lower lids L/R, lashes/eyeline L/R, mouth base, lips, mouth interior, teeth, tongue optional, blush optional.

### HAIR
hair_back, rear groups, side L/R, hair_front, bangs, face-lock strands.

### OUTFIT STATIC/DEFORMABLE
canonical top/chest piece, bottom/waist piece, armwear L/R, boots/shoes L/R, textile/deform groups.

### DYNAMIC ACCESSORIES — SOLO COME LAYER SEPARATI
Riferire i componenti creati nel Prompt 09: earrings L/R, necklace/choker dynamic, chains, pendants, gems/charms, hair/boot/wrist accessories mobili.

Non disegnare gli accessori fusi sulla BASE CLEAN.

## Parametri minimi
ParamAngleX/Y/Z, BodyAngleX/Y/Z, EyeBallX/Y, EyeLOpen, EyeROpen, MouthOpenY, MouthForm, brow params, Breath, hair physics, chest/bust physics, accessory physics.

## Output
Solo figura base + diagramma tecnico indispensabile. Niente concept art, palette decorative o nuove varianti outfit.

## Criteri di accettazione
- stesso outfit canonico della METRIC MASTER;
- BASE CLEAN senza accessori dinamici;
- L/R esplicito;
- accessori separati e collegati al Prompt 09;
- nessuna reinterpretazione del personaggio;
- struttura compatibile col target mobile e senza layer ridondanti.
